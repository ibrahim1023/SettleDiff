# Bug and AI slop audit — 2026-10-12

Reviewed the recently changed x402 signed-evidence, live CLI, telemetry, and eval
paths, their actual consumers, tests, and accepted ADRs. A separate read-only
architecture review applied the deletion test to those modules. This is a scoped
correctness and maintainability audit, not an exhaustive security assessment.

## Fixed bugs

| Bug | Previous behavior | Correction | Regression |
|---|---|---|---|
| Ambiguous seller JSON | Duplicate JWS header/payload or DID keys silently used the last value; nonfinite numbers were accepted by JSON decoding | Reject duplicate members and nonfinite numbers through one seller JSON interface | Signed-evidence and seller-identity tests |
| Malformed receipt transaction | Present null, numeric, boolean, empty, array, or object values received the warning for optional omission | Mark malformed signed receipts explicitly; only an absent optional transaction receives the omission diagnostic | Six malformed-transaction cases |
| Challenge redirects | A supplied redirect-following HTTP client could send the request to another resource | Explicitly disable redirects on challenge requests | Mock transport proves one request and preserves the redirect response |
| Incomplete eval promotion | A manifest could omit required replay files while the source still replayed successfully; the copied eval then failed | Require contract, execution, and Activity files before output creation | Each omitted required artifact refuses promotion without writing output |
| Early telemetry cleanup | A database initialization failure exited before telemetry shutdown | Put initialization inside the cleanup scope, delay HTTP client construction, and run shutdown even if repository close fails | CLI database initialization failure asserts exactly one shutdown |

## Cleanup

Deleted `NullTelemetrySpan`, a custom no-op context manager used twice.
`contextlib.nullcontext()` provides the same behavior and exception propagation,
removing 13 net lines. Existing application and agent tests cover both telemetry
and no-telemetry paths.

No broad rewrite, new wrapper layer, or extra dependency was justified. The signed
extension parser, deterministic signature findings, eval graders, and telemetry
metric interfaces have real consumers and focused tests. Existing privacy and
financial-evidence rules remain in force.
